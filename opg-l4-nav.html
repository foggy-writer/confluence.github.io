Quickstart Integration

Initialize the client cluster and establish an encrypted pub-sub channel cleanly using vanilla JavaScript or modern JS runtimes.

cluster-init.ts 
import { Cluster } from '@enterprise/core';

// Connect to regional cluster
const cluster = await Cluster.connect({
  region: 'us-east-1',
  authToken: process.env.CLUSTER_SECRET
});

const stream = cluster.subscribe('telemetry-events');
stream.onData((event) => console.log(event.id));
