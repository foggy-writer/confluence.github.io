Audience Console

A tool that provides access to the Omnicom Audience data stack, driven largely by Acxiom data sources. This provides thousands of attributes for audience segment creation - demographic, attitudinal, behavioral, and location.

Use Cases

By leveraging multiple available data sources, users can:

  • 01. Audience Insights Investigate potential audiences and uncover audience insights.
  • 02. People-Based Segments Create and identify people-based audience segments.
  • 03. Customer Analysis Generate customer analysis and insights for actionable intelligence.
  • 04. Platform Activation Activate audience segments directly from the platform.
