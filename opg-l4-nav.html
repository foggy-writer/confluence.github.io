Quickstart & Code Example

Initialize the client cluster and establish an encrypted pub-sub channel in under 5 lines of code.

cluster-init.ts 
import { Cluster, StreamEngine } from '@enterprise/core';

// Initialize multi-region cluster client
const cluster = await Cluster.connect({
  region: 'us-east-1',
  authToken: process.env.CLUSTER_SECRET,
  retryStrategy: 'exponential'
});

const stream = cluster.subscribe('telemetry-events');
stream.onData((event) => console.log('Stream Payload:', event.id));
